Docker & Kubernetes

Dos tecnologías centrales en cualquier stack DevOps moderno. Las uso juntas para empaquetar, distribuir y orquestar aplicaciones de forma confiable en producción sobre AWS.

🐳

Docker

Containerización

Docker es la base de cualquier estrategia de containerización moderna. Permite empaquetar una aplicación con todas sus dependencias en una imagen portable, reproducible y aislada que corre igual en cualquier entorno — desde el laptop del dev hasta producción en AWS.

▸
Imágenes optimizadas

Multi-stage builds para separar etapas de compilación y runtime. Uso de imágenes base Distroless o Alpine para reducir superficie de ataque y tamaño final.

▸
Docker Compose para desarrollo

Defino entornos de desarrollo reproducibles con docker-compose: base de datos, cache, servicios y redes en un solo archivo. Lo que corre localmente, corre en CI.

▸
Registros privados en AWS

Gestión de imágenes en Amazon ECR con lifecycle policies, escaneo de vulnerabilidades automático y acceso vía IAM roles sin credenciales hardcodeadas.

▸
Seguridad en containers

Contenedores non-root, read-only filesystem, límites de recursos (CPU/mem), escaneo con Trivy y policies de imagen en pipelines CI/CD.

DockerfileMulti-stageDocker ComposeECRTrivyAlpine
⎈

Kubernetes

Orquestación

Kubernetes es el estándar de orquestación de contenedores en producción. Gestiona el ciclo de vida de los pods, el escalado automático, el service discovery y los deploys sin downtime. En AWS lo uso principalmente a través de EKS (Elastic Kubernetes Service).

▸
EKS en AWS

Provisiono y opero clusters EKS con Terraform. Configuro node groups con Karpenter para autoscaling eficiente, integración con ALB Ingress Controller y gestión de add-ons nativos (CoreDNS, kube-proxy, VPC CNI).

▸
GitOps con Argo CD

El cluster siempre refleja el estado declarado en Git. Argo CD detecta cualquier divergencia y reconcilia automáticamente. Deploys auditables, reversibles y sin acceso kubectl manual en producción.

▸
Zero-downtime deployments

Estrategias de despliegue con Argo Rollouts: Canary releases y Blue/Green deployments con análisis automático de métricas. Si algo falla, el rollback es inmediato y automático.

▸
Escalado & eficiencia

HPA para escalar pods por CPU/memoria o métricas custom, VPA para right-sizing automático y Karpenter para aprovisionar nodos bajo demanda — incluyendo instancias Spot para reducir costos.

Sobre mí

Soy DevOps & Cloud Engineer especializado en AWS, con experiencia diseñando, automatizando y operando infraestructura cloud para equipos de alto crecimiento. Trabajo sobre todo el ciclo: desde containerizar una aplicación con Docker hasta orquestarla en Kubernetes, pasando por el pipeline de CI/CD y la observabilidad en producción.

Mi enfoque es infraestructura como código desde el día uno: cada recurso AWS declarado en Terraform, cada deploy trazable en Git, cada métrica visible en Grafana. Creo que un buen sistema DevOps es el que libera tiempo al equipo de desarrollo para enfocarse en producto — no en apagar incendios.

Trabajo de forma independiente con startups que necesitan base sólida en cloud, equipos que migran workloads legacy a contenedores, o empresas que quieren escalar su plataforma sin que los costos ni los incidentes escalen al mismo ritmo.
